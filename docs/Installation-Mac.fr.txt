ATRAMENTUM – INSTALLATION (MAC)
===============================

Atramentum est gratuit. Il n'existe ni version payante, ni compte, ni
inscription. Atramentum n'a pas besoin d'Internet et n'envoie jamais vos
textes ni vos données personnelles où que ce soit. Uniquement si vous
l'autorisez, il vérifie sur GitHub, au plus une fois par jour, si une
nouvelle version est disponible.

Configuration requise : macOS 13 (Ventura) ou version ultérieure,
Apple silicon ou Intel.


1. Installation
---------------
Faites glisser « Atramentum » de cette image disque sur « Applications ».
Vous pouvez ensuite fermer cette fenêtre et éjecter l'image disque.


2. Premier lancement
--------------------
Atramentum n'est pas notarisé par Apple : macOS affiche donc un
avertissement la première fois que vous l'ouvrez. Cela ne se produit
qu'une seule fois.

  a) Double-cliquez sur Atramentum dans « Applications ».
     macOS indique qu'il ne peut pas vérifier Atramentum. Cliquez sur
     « Terminé » (et non sur « Placer dans la corbeille »).
  b) Ouvrez Réglages Système > Confidentialité et sécurité.
     Plus bas, vous verrez un message concernant « Atramentum ».
     Cliquez sur « Ouvrir quand même ».
  c) Confirmez avec « Ouvrir » et votre mot de passe ou Touch ID.

Atramentum démarre ensuite normalement.

Si macOS indique au contraire qu'Atramentum est « endommagé », le fichier
a été modifié pendant le téléchargement. Téléchargez-le à nouveau depuis
la page officielle et comparez la somme de contrôle (voir 5.).

Atramentum s'affiche automatiquement dans la langue de votre système
(en anglais si celle-ci n'est pas prise en charge). Pour en changer :
Présentation › Langue …


3. Mise à jour
--------------
Atramentum propose lui-même les mises à jour (Aide ou Atramentum >
Rechercher des mises à jour …) : un clic suffit pour télécharger,
vérifier et installer la nouvelle version.
Manuellement : téléchargez la nouvelle version, faites-la de nouveau
glisser sur « Applications » et choisissez « Remplacer ». Vos projets ne
sont pas concernés : ils ne sont pas enregistrés dans l'application, mais
dans le dossier « Atramentum » de votre dossier de départ.
Lorsque le format de fichier change, Atramentum sauvegarde
automatiquement le projet avant de le convertir.


4. Désinstallation
------------------
  - Application : placez « Atramentum » d'« Applications » dans la
    corbeille.
  - Réglages et sauvegardes automatiques (facultatif), dans le Finder
    via Aller > Aller au dossier … :
      ~/Library/Application Support/io.github.sammielpadre.atramentum
      ~/Library/WebKit/io.github.sammielpadre.atramentum
      ~/Library/Caches/io.github.sammielpadre.atramentum
  - Vos projets se trouvent dans ~/Atramentum (ou à l'endroit où vous les
    avez créés). Ils ne sont PAS supprimés lors de la désinstallation.
    Ne supprimez ce dossier que si vous n'avez vraiment plus besoin de
    vos textes.

Remarque : le dossier « Application Support » contient les sauvegardes
quotidiennes automatiques de vos projets. Conservez-le en cas de doute.


5. Vérifier le téléchargement
-----------------------------
Une somme de contrôle SHA-256 est publiée pour chaque version. Dans le
Terminal :

    shasum -a 256 ~/Downloads/Atramentum-*.dmg

La valeur affichée doit correspondre à la valeur publiée.


Aide et commentaires : dans Atramentum, sous Aide.

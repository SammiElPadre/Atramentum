Datenschutz

Kurz gesagt: Atramentum sammelt keine Daten. Ihre Texte, Figuren, Notizen und Einstellungen bleiben auf Ihren Geräten. Es gibt kein Konto, keine Werbung, keine Analyse und keine Tracker.

Die App

  • Ihre Projekte speichert Atramentum nur dort, wo Sie es festlegen: auf Ihrem Gerät oder einem Datenträger Ihrer Wahl. Atramentum überträgt sie nirgendwohin.
  • Abgleich zwischen Geräten läuft über einen Ordner, den Sie selbst wählen, etwa in iCloud Drive, Dropbox oder OneDrive. Atramentum legt dort nur Änderungspakete ab. Für diese Dienste gelten deren eigene Datenschutzbestimmungen. Ohne eingerichteten Abgleich verlässt nichts Ihr Gerät.
  • Rechtschreibprüfung, Vorlesen und Diktat nutzen die Dienste Ihres Betriebssystems. Das Diktat auf dem Mac erkennt Sprache auf dem Gerät, wenn macOS das für die gewählte Sprache kann; sonst übernimmt die Spracherkennung von Apple. Auf iPhone, iPad und Android bestimmt die Tastatur Ihres Systems, wie das Diktat arbeitet.
  • Updates: Die Fassung aus dem App Store bezieht Updates über den App Store. Die Fassungen von GitHub fragen beim Start bei GitHub nach, ob es eine neue Version gibt. Dabei sieht GitHub, wie bei jedem Webseitenaufruf, Ihre IP-Adresse. Atramentum sendet keine weiteren Angaben mit.
  • Links (Fehler melden, Spenden) öffnen Ihren Browser. Erst wenn Sie einen solchen Link anklicken, entsteht eine Verbindung zu GitHub bzw. Ko-fi.
  • Trinkgeld im App Store: Käufe wickelt Apple ab. Atramentum erfährt davon nur, dass ein Kauf erfolgreich war.

Diese Webseite

Die Webseite liegt bei GitHub Pages. GitHub verarbeitet beim Aufruf technisch notwendige Daten wie Ihre IP-Adresse (siehe Datenschutzerklärung von GitHub). Für die Anzeige der Download-Zahl ruft die Seite in Ihrem Browser öffentliche Angaben bei GitHub ab. Die Seite setzt keine Cookies und lädt keine Tracker.
